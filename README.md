- שם: NEON AI.
- עיצוב עתידני עם אפקטים של ניאון כחול וסגול, אנימציות ומראה מקצועי.
- ממשק בעברית מלאה ובכיוון RTL, עם תמיכה גם באנגלית.
- התאמה לטלפון ולמחשב.
- תפריט ברור, כפתורים שעובדים, טעינה מסודרת והודעות שגיאה מובנות.
- שמור על העיצוב הקיים שלי ככל האפשר ואל תמחק תכונות שכבר קיימות.

2. צ'אט AI אמיתי

- לחבר את הצ'אט למודל Gemini דרך השרת.
- שה-AI יענה על שאלות, יסביר דברים, יעזור בלימודים, יכתוב בעברית ויבין הקשר בשיחה.
- לא להשתמש בתשובות קבועות או מזויפות.
- להציג טעינה, שגיאות ואפשרות לשלוח הודעה גם באמצעות Enter.

3. יצירת תמונות AI

- המשתמש יכתוב תיאור והתוכנה תיצור תמונה אמיתית.
- להציג את התמונה באתר ולא רק קישור.
- להוסיף טעינה, טיפול בכישלון ואפשרות לשמור תמונה.
- להשתמש בשירות חינמי אם קיים ומתאים, ולהסביר אם צריך API בתשלום.

4. עוזר כתיבה

- כתיבת סיפורים, עבודות, הודעות, רעיונות, תיאורים וסיכומים.
- להשתמש ב-AI אמיתי ולא בטקסט לדוגמה קבוע.

5. עוזר תכנות

- יצירת קוד, הסבר על קוד, תיקון באגים וכתיבת קבצים.
- לאפשר למשתמש להעתיק ולהוריד קוד.
- להשתמש ב-Gemini דרך השרת.

6. יצירת משחקים

- המשתמש יכתוב איזה משחק הוא רוצה וה-AI יעזור ליצור משחק אמיתי שאפשר לשחק בו.
- להתחיל במשחקי HTML שאפשר להציג באתר ולשחק בהם.
- להוסיף משחקים עם תנועה, מקלדת ומגע בטלפון, ניקוד ושלבים כשמתאים.
- לא להסתפק בתיאור של המשחק או בקוד שאי אפשר להפעיל.
- אם אפשר, ליצור קובץ HTML למשחק ולהציג תצוגה מקדימה בטוחה.

7. כלי Roblox

- יצירת סקריפטים אמיתיים ל-Roblox Studio לפי בקשת המשתמש.
- הסברים היכן להכניס כל סקריפט.

8. כלי VR

- יצירת דוגמאות ופרויקטים בסיסיים ב-WebXR או A-Frame.

אני רוצה אפשרות מיוחדת ליוצר האתר, כדי שאוכל להשתמש בכל כלי NEON AI בלי לשלם מנוי.

11. הטכנולוגיה והקבצים
אני רוצה להשתמש ב-Netlify לאתר וב-Render לשרת Node.js. השתמש ב-Gemini דרך ה-SDK הרשמי והתאם את שם המודל למודל שנתמך בפועל בזמן ההכנה.

החזר לי:

1. קובץ index.html מלא.
2. קובץ server.js מלא.
3. קובץ package.json מלא.
4. קובץ .gitignore.
5. קובץ netlify.toml אם נדרש.
6. קובץ README.md עם הוראות בעברית.
7. כל קובץ נוסף שבאמת נחוץ.

הסבר כיצד לפרסם דרך GitHub, לחבר את Render ואת Netlify, להגדיר את GEMINI_API_KEY ואת קוד היוצר במשתני סביבה, ולחבר את כתובת השרת לאתר.
